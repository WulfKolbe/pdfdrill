THE INSTRUMENT
--------------
An existence test, not a typeset probe:

  \expandafter\ifx\csname NAME\endcsname\relax \write16{MISSING:NAME} \fi

Typesetting `$\cmd$` to see whether it errors confuses three questions —
undefined, defined-but-missing-its-argument, defined-but-illegal-here. The
csname test asks only the one being asked, needs no arguments, and runs every
name in one xelatex pass. (Side effect recorded rather than hidden: `\csname`
makes an undefined name equal to `\relax`, so each name is tested once.)

AND THE LARGER HALF IS NOT A PACKAGE GAP AT ALL
-----------------------------------------------
11,088 of the 11,624 occurrences — 95% — are commands no candidate package
defines. They are the SOURCE DOCUMENT'S OWN MACROS, and the census makes that
visible for the first time:

  \psline 1003, \pscircle 571, \psset 466, \psarc 455, \rput 404,
  \Rnode 393, \ncline 318, \pspicture 285, \endpspicture 285

  — PSTricks, every one of them in a SINGLE document. 4,180 occurrences from
    one book whose figures are PSTricks source that MathPix read as maths.

  \mv 488, \on 376, \kbrowsep 252, \la 240, \g 206, \rom 203, \OO 161,
  \mc 166, \Z 169, \C 183 — author macros, defined in that document's own
  preamble and meaningless outside it.

167 of the 196 appear in exactly one document. Loading packages cannot fix
any of it; only injecting the author's preamble can, which is what
`injectlatex` exists for and what out/056's 286 note already measured (author
preamble alone took a 10-document sample from 66.7% to 52.2%, so it is not a
free win either).

WHAT I RECOMMEND, AND WHAT I DID NOT DO
---------------------------------------
Four packages — bm, mathtools, extarrows, stix2 — cover ~500 occurrences and
close every gap found one-at-a-time so far except the author macros. `braket`
would add 178 more (\ket + \bra).

I did not add them. The preamble is loaded by every build in the corpus and
mathtools patches amsmath internals; the change wants its own task with a
corpus compile behind it, which is exactly the argument for doing it once.
This census is what that task should be sized against.

Nothing was changed.
