RECONSTRUCTIBLE — `PROPOSE_PROMPT_C`, my `ERR_LINE` and the stored `latex`, at

WHERE IT LANDS NOW

    <blob_dir>/calls/<run_id>.jsonl

    run_id = 20260901T073156Z-refine444-26b115f3
             UTC stamp · tool · 8 hex — sortable, unique, self-naming

Beside the document, never a scratchpad. One file per RUN, one JSON object per
CALL, APPENDED as the run proceeds — a run killed half way still leaves what
it already spent, which a buffered writer would lose.

WHAT A COMPLETED RUN LEAVES

  header   run_id, tool, script path, note, started, COMMIT, pid
  call     at, subject, arm, model, max_tokens, seconds, finish, error,
           system, prompt, reply, images
  footer   calls, outcome, ended

Verbatim. Nothing redacted, nothing truncated: a redacted prompt is not the
prompt that was sent, and a truncated one cannot be re-sent. If a prompt must
not be kept, it must not be sent. The API key never enters the record because
it is never in the prompt.

`arm` is the field 444 needed and did not have. Two calls about one subject
differing by a line of prompt are a comparison only if the record says which
was which.

THE HOOK IS MODULE-LEVEL, DELIBERATELY

    refine.set_call_log(blob_dir, run_id)

and `_novita_chat` became a thin wrapper over `_novita_chat_raw` that logs
every call. Not a parameter on each call site: threading an argument through
is exactly the thing that gets forgotten, and the point is that a runner
CANNOT forget. A logging failure is swallowed — it must never cost the paid
answer that was just bought.

TWO SMALL THINGS FOUND WHILE DOING IT

A stray `v.json` appeared in the evidence directory, pretty-printed rather
than JSONL. `callog.path_for` always appends `.jsonl`, so it cannot have come
from here — it was a shell-quoting slip of mine on a path carrying both spaces
and parentheses. `runs_for` globs `*.jsonl`, so it was never readable as a
run; there is now a test saying so.

And two existing tests monkeypatched `_novita_chat` with a fake whose
signature did not admit the new `subject`/`arm`. They now take `**kw`: a fake
standing in for a real signature has to tolerate that signature growing, or it
pins the shape instead of the behaviour.
