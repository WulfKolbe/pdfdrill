THE AMBIGUITY IS THE FINDING
------------------------------------------------------------------------------
   82 of the 119 covered listings have more than one \lstset
   language that could apply to them. \lstset is a DECLARATION with
   document order semantics: it applies from where it appears until the
   next one, and papers that show several languages re-issue it repeatedly.
   Resolving those correctly needs the last \lstset before the listing in
   the flattened input order — not the file order this measurement has,
   because \input and \include mean file order is not document order.

   Examples of documents with competing defaults:
     1609.04938v1                 ['[LaTeX]TeX', 'html']
     2009.11564                   ['HTML', 'Java']
     2310.10631v3                 ['isabelle', 'lean']
     arXiv_2009.11564             ['HTML', 'Java']

SO THE HONEST ANSWER
------------------------------------------------------------------------------
   A global default rescues 37 listings unambiguously.
   It is PRESENT for 119 but under-determined for 82 of them.
   119 listings have no default at all.

   Combining with 084: of the 227 listings with neither language nor
   caption, 35 would gain an unambiguous language from an \lstset,
   leaving 192 with no declared type and no name by any route.
