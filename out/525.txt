525 — a measurement writes its script and its result beside the document
========================================================================

THE RULE, NOW IN CODE AND IN THE RULES FILE
--------------------------------------------
`src/pdfdrill/taskout.py`; HANDOVER-RULES.md rule 19.

  <document>/out/<NNN>/script.py   the exact source that ran
  <document>/out/<NNN>/*.json      what it produced

`save_script`, `save_json`, `save_text`, `paths`, `report_lines`. A
corpus-wide scan measures no one document and writes to
`~/pdfdrill-library/out/<NNN>/` rather than picking one arbitrarily.

WHY THE LIBRARY AND NOT THE REPO. The repo is public; the library is
deny-by-default git — `.gitignore` opens with `/*`, so nothing under
`<document>/out/` can be committed by accident. Verified, not assumed:

  $ git check-ignore -v out/525/audit.json
  .gitignore:15:/*   out/525/audit.json

Measurements quote copyrighted text; reports about them do not. This puts
the evidence where the document is and keeps it out of the public tree.

447 established exactly this for LLM calls — every prompt and every reply
kept beside the document — and it was never generalised to measurements.

WHY THIS IS NOT TIDINESS
-------------------------
522 found `latex_similarity` scoring one pair 0.857 in one argument order
and 0.005 in the other, on identical strings. Every score in every
`compare.html` was computed the broken way. Nothing in the artefact said
so, and nothing could have: the score was a number on a page with no path
back to the code that made it.

That is the general shape. The measurements have been sound; the artefacts
are stale or wrong; and an artefact is what gets inspected. Twenty tasks of
findings, and the files opened were built before most of them.

---------

`audit.json` carries, per task, the committed script, the committed data,
the scratchpad scripts, the scratchpad file count and whether it wrote into
the library. Re-running `script.py` reproduces the table above.
`tools/audit525.py` is the same script in the repo so the classification
can be checked without the library.

NOT DONE
--------
The 53 scratchpad files are not migrated. Most are intermediates of
superseded runs and the rule explicitly permits intermediates; the ones
worth keeping are the five class-B scripts, and they are worth re-running
under the rule rather than copied, because a script whose output was never
saved is not evidence either.
