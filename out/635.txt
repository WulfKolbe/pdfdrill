FIX ROUND 1 — three findings from review, ruled real, addressed
--------------------------------------------------------------------------

#1 CRITICAL — the test/suite counts above were wrong and disagreed with
each other. Fixed by re-running the suite ONCE, after all other fix-round-1
changes, and recording that single number (3338 passed) plus the correct
new-test count (13 = 9 + 4) in both this file and the task report. No other
content changed to produce this number — it is the actual state of the
tree.

#2 IMPORTANT — the wreckage Sections were dropped by CAPTION ALONE,
document-wide, gated only on "a Toc exists somewhere". A real section
titled "Contents" on some unrelated page would have vanished. RULING
implemented literally: `src/docops/projectors/latex.py`'s `_prepare` now
requires a caption match AND ONE of —
  (a) the Section's own realization's `_page` is one of the pages the Toc's
      own realization spans (measured on penev_A: the Toc spans pages
      {2, 3}, and BOTH "Contents" and "List of Figures" sit on page 2 —
      one of those pages — so this check alone already covers penev_A's
      real case); or
  (b) the Section's anchor precedes the Toc's own span-start anchor by at
      most `_TOC_HEADER_PRECEDE_BOUND` (= 2) mathpix_lines positions — the
      MEASURED distance on penev_A ("List of Figures" is 1 line before the
      Toc's first `table_of_contents_*`-typed anchor, "Contents" is 2),
      stated as the constant rather than left as a magic number, and kept
      as a fallback for a document whose preceding heading's page happens
      to be missing/None.
A caption match that fails BOTH checks is KEPT — not dropped — and counted
under a new `self._toc_wreckage_title_kept: dict[type, int]`, printed by
`cmd_latex` as `toc_wreckage_title_kept: <n> <Type> (... kept)` whenever
non-empty. New test (`tests/test_latex_projector.py`):
`test_a_real_contents_section_far_from_the_toc_is_kept_and_counted` — a
Section "Contents" 37 lines past and one page past a Toc on an earlier
page is KEPT, `\section{Contents}` is in the output, and
`toc_wreckage_title_kept["Section"] == 1`. Confirmed failing against the
round-0 code (git-stashed, re-run): `AssertionError` on `\section{Contents}
in tex` (round 0 dropped it unconditionally).
MEASURED ON penev_A: 0 change. `toc_wreckage_title_kept` is empty (all 3
wreckage Sections pass check (a), being on the Toc's own pages) — the
23/3/2 counts do not move; see THE NUMBERS AFTER FIX ROUND 1 below.

#3 IMPORTANT — non-Section suppression fired when ANY realization of an
object touched the Toc's span. `FormulaProcessor` merges identical LaTeX
into ONE object carrying SEVERAL realizations (penev_A's "T=87" Formula has
six), so an object whose real, standalone-printed occurrence is body text
elsewhere, but which also happens to share its exact LaTeX with a TOC
fragment, would have lost its ONLY rendering to this rule. RULING
implemented literally: suppression is now keyed to the object's FLOW
realization — `next(r for r in obj.realizations if r.stream ==
"mathpix_lines" and r.start is not None)`, the EXACT selection
`document_flow.DocumentFlowProcessor` uses to place the object's
`flow_index` (`surface[0]`). If the flow realization's line is in the Toc's
span, suppress (counted under `toc_region_suppressed`, unchanged shape). If
only a SECONDARY realization touches the span while the flow realization
does not, the object is KEPT and counted under a new
`self._toc_fragment_shared: dict[type, int]`, printed by `cmd_latex` as
`toc_fragment_shared: <n> <Type> (...)`. Two new tests
(`tests/test_latex_projector.py`):
`test_a_shared_formula_flow_position_outside_the_toc_is_kept` (flow
realization is real body text, a SECONDARY realization repeats inside the
Toc — kept, `toc_fragment_shared["Formula"] == 1`) and
`test_a_shared_formula_flow_position_inside_the_toc_is_suppressed` (the
mirror: flow realization IS the Toc occurrence even though a later
realization is real body text — flow_index is ONE property/ONE slot, so
suppressed, `toc_region_suppressed["Formula"] == 1`, NOT
`toc_fragment_shared`). Both confirmed failing against the round-0 code.
MEASURED ON penev_A: 0 change. Re-checked exhaustively (as round 0 already
had): every one of the 26 non-Section objects (23 Formula + 2 Sidenote + 1
Section-via-title) whose ANY realization touches the Toc's span ALSO has
that same object's FLOW realization inside the span — 0 counterexamples —
so keying to the flow realization instead of "any realization" changes
NOTHING on this document; `toc_fragment_shared` is empty.
