WHAT IS LEFT, AND WHY EACH CLASS RESISTS REPAIR
------------------------------------------------
  2  HALLUCINATED SCRIPT (EQ1032, EQ1187)
     U+2FF0-U+2FFB are Ideographic Description Characters — not glyphs, but a
     notation for describing how an unknown ideograph is composed. Their
     presence means MathPix could not identify a character and emitted its
     recipe. There is nothing to repair: the content is wrong, not malformed.
     EQ1187 also carries \zh. These are the rows to re-OCR, and out/129 names
     EQ1187 as the one to send back with its crop.

  5  BARE ALIGN MARKER (EQ0037, EQ0696, EQ0802, EQ0922, EQ0939)
     A bare `&` or `\\` at brace depth 0 is a longtable TAB MARK. Left in, it
     throws "misplaced tab mark" and sends xelatex into an error-recovery loop
     the row-demotion pass never reaches — a live hang, not a failed row.
     Refusing them is deliberate and correct.

     These are repairable in principle: the value is multi-line mathematics
     that lost its environment, and wrapping it in \begin{aligned}...\end{aligned}
     would give the markers a home. That is a real transform on OCR output
     rather than a cosmetic strip, so it is not folded in here.

     Note the confidences: 0.10 to 0.55, three of them ABOVE 0.5. MathPix is
     not signalling doubt about these — the defect is structural, and the
     confidence column does not predict it.

  1  GENUINE COMPILE FAILURE (EQ0689, confidence 0.914)
     `\left\{\begin{array}{ll} ... \end{array} \quad\right` — a \right with no
     delimiter after it. Well-formed enough to pass every static gate and still
     invalid TeX. The highest-confidence row of the eight, which is the useful
     part: a 0.914 value can still be unrenderable, so the confidence column
     cannot be used as a rendering predictor.
