PER ENVIRONMENT - THE TWO SOURCES DISAGREE SYSTEMATICALLY
------------------------------------------------------------------------------
                  author e-print     MathPix tex.zip
    lstlisting           0                 9
    minted               0                 0

    algorithm            8                 0

   MathPix never emits algorithm and the authors never emit lstlisting.
   All 8 documents whose author source opens the algorithm environment come
   back from MathPix as lstlisting — 8 of 8, no exceptions.

   An algorithm float is a structured object: numbered lines, keywords, a
   caption, a float position. lstlisting is a verbatim code block. The
   content survives the conversion and the structure does not.

   Consequence for anything comparing the two sides: an algorithm in the
   author source will NEVER match by environment name. A comparison keyed
   on the environment would report 100% disagreement on all 8 and would be
   measuring the mapping rather than the OCR.
