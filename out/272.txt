WHAT THIS MEANS FOR 259 AND 265
------------------------------------------------------------------------------
259's font_size ranking is not useless and 265's "it fires once" was not the
whole story. The ranking is MASKED by command precedence in precisely the 249
documents where it would help: every header carries a command, so the command
wins, and the command is the same for all of them.

The precedence itself is still right where the command carries information —
the author's own `\subsection*` beats an inference from pixel height. It is
wrong where the command carries NO information, which is detectable without
guessing: a document whose headers all bear the same command AND span more than
one font size has a hierarchy the command is not expressing.

Recorded as open, not fixed — 272 is a reporting step, and this is a change to
level assignment that deserves its own measurement rather than being folded
into a report about the current state:

    Section levels — where every header shares one command but the document
    has 2+ header font sizes, the command carries no depth and font_size
    should decide. 249 documents, 6,979 Sections, ~2.6 levels recoverable.

WHY level 3+ IS STILL ZERO
------------------------------------------------------------------------------
Unchanged from 265 and now with the reason attached: `\subsubsection`,
`\paragraph` and `\subparagraph` occur 0 times in 43,159 headers. MathPix's
section vocabulary in this corpus is `\section*` and `\subsection*` only. So the
model cannot express a third level from commands, and the 249 documents above
are where a third level actually exists in the page.

Nothing changed in this task.
