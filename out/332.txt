  through \input, and standalone_preamble was reading the root file
  alone.

  Expanding first: preamble 393 -> 2,135 chars, compiled 29 -> 46.

  The same call is missing in commands._render_regions, which extracts a
  preamble the same way for the region renders. Not changed here -- that
  is a live pass's input and a separate measurement.
