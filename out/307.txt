WHAT THE RULE IS
  \begin{array}{c|c|c|c|c|c|c} declares seven columns; a row with five is
  a transcription that lost entries, and LaTeX sets it without complaint.
  189 named this remedy and left it unbuilt.

  It shares no code with check_uniform_widths and catches three classes
  that rule cannot see:
    - uniformity needs >=60% of cells to be bare numbers, so a symbolic or
      mixed table is never examined at all;
    - uniformity compares rows to EACH OTHER, so a table short by the same
      amount on every row is perfectly uniform and perfectly wrong;
    - uniformity needs two rows to have an opinion; a one-row array is
      checked here.
