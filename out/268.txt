------------------------------------------------------------------------------
1. Self-closing widget bodies are far more numerous than empty bodies:

       idea14         823 widget bodies  ->  101 empty
       2004.05631v1 1,539 widget bodies  ->  152 empty

   The difference is Formula and most Equations. Their bodies are destroyed the
   same way, but `_okf_body` special-cases those two types and reads the `latex`
   FIELD instead of the converted text, so the file is populated anyway. They
   are NOT part of class B's count and must not be counted as fixed by 270.
   `2004.05631v1`'s single empty Equation is the one whose `latex` field is
   itself empty, so the rescue has nothing to read.

2. Sidenote appears in the empty-body counts (5 and 14) and is class C, not
   class B — its tiddler `text` is already `''` before okf runs. 270 must leave
   those empty, and 267's third cross-check is exactly that: a body still empty
   after the fix has to be empty in the model too.
