390 - the rescue population: where MathPix gave up on a region
==============================================================

WHERE IT LIVES. There are no .mmd files in the library at all - 0 of 2,810
documents. MathPix's own LaTeX output is the tex.zip archive, 1,219 of them,
and the crops ship INSIDE it:

    <uuid>/<uuid>.tex
    <uuid>/images/<uuid>-<page>_<h>_<w>_<y>_<x>.jpg

The filename encodes the rectangle, which is what makes a rescue site
identifiable rather than merely an image. Scanned in place with zipfile; no
archive was extracted.

298 measured the AUTHOR's inclusions and explicitly set this population
aside - "texsrc/ also holding a MathPix tex.zip extraction: 6 docs, 205
calls (excluded below)". That exclusion was reading the 6 extracted texsrc/
copies. Read from the archives instead, the population is a hundred times
larger.

NOT ALL OF IT IS A RESCUE, and the filename says which
------------------------------------------------------

  kind                             refs   docs   crop on disk
  region crop                     20827    929      20827
  image-not-found placeholder         9      8          9

A ref that parses as <page>_<h>_<w>_<y>_<x> is MathPix naming a rectangle it
declined to transcribe. The other three kinds are not that, and lumping them
in would have inflated the population with things no rescue can act on:

  `image-not-found` is a MARKER, not a picture. All 9 members are the same
  427 bytes - one placeholder file. MathPix wanted a region here and could
  not produce a crop either, so there is nothing to send a model.

  `smile-<hash>` is chemistry: a rendered chemical structure. A real region
  with a real crop, but a different recovery problem from a figure.

  `myfigure`, `./shell.eps`, `router.pdf`, `curve`, `#2` are MathPix
  TRANSCRIBING PRINTED SOURCE CODE. All 10 come from 3 documents and every
  one is a book about LaTeX - IEEEtran_HOWTO, Kottwitz's TikZ guide,
  latex2-script. The OCR read an \includegraphics printed as an example and
  emitted it as an \includegraphics. Not a rescue: the picture was never
  missing, it was never there.

WHAT THIS IS FOR

Every one of the 20,833 is a rectangle MathPix saw, cropped, and handed back
untranscribed. The crop is on disk and the region is in its name, so each is
a self-contained recovery task with the picture already cut out.

What it is NOT is a measured opportunity. Nothing here says a recovery would
be CORRECT - a rescued figure has no reference to check against, which is
exactly 281's position. 392 answers that on rows where the author's code is
known; this file only says how many there are.
