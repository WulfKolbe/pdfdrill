A MISTAKE I MADE WHILE FIXING IT
---------------------------------
I rebuilt with `./pdfdrill breport "$D"/*.pdf`. The glob expands
alphabetically and `B.pdf` sorts first, so the build ran on B's OWN output
— 1,994 rows where cardona has 4,820 — and overwrote cardona's B.tex and
B.pdf with a report about a report. Caught because the row count changed;
rebuilt from the explicit source path and back to 4,820 rows. A document
folder now contains three PDFs and a glob is no longer safe in it.
