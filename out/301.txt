==================================================================

  document              author calls   regions   usable as ground truth
  1012.3259                  0          34   NO - texsrc/ holds only the tex.zip
  1802.08153                 0          24   NO - texsrc/ holds only the tex.zip
  2004.05631v1             100         134   yes

  2502.20855v2               3           9   yes
  bh2                        0           1   NO - texsrc/ holds only the tex.zip

  Four of the six have no author sources at all: their texsrc/ contains
  the unpacked MathPix tex.zip and nothing else. A join from the author's
  figure FILES to MathPix's regions has no left-hand side there, so those
  four can score nothing.

HOW TRUTH IS ESTABLISHED

  Not by order. Checking an order-based join against an order-based truth
  reports the join's own assumption back as its accuracy. Truth here is the
  CAPTION: MathPix OCRs the caption the author wrote, so it is content both
  sides carry independently. A pair is known only when a run of >=5 caption
  words appears beside exactly ONE region, and only when that region is
  claimed by exactly one author inclusion.

  2004.05631v1
    author inclusions 100, MathPix regions 134, lengths agree: False
    known pairs 7 | contested 1 (dropped) | unanchored 91
      contested (53, 1359, 819, 889, 380) claimed by ['figures/ch2/bestproof1', 'figures/ch2/bestproof2']
  2502.20855v2
    author inclusions 3, MathPix regions 9, lengths agree: False
    known pairs 1 | contested 0 (dropped) | unanchored 2

SCORE OF THE INFERRED JOIN (the k-th author figure is the k-th region)

  checkable pairs   : 8
  MATCHED           : 0
  WRONG             : 8
  not inferred      : 0

  The join answered every checkable pair and was wrong on every one. It
  never declined. An answer that is always produced and sometimes wrong is
  indistinguishable from a correct one until it is scored - which is 282's
  defect exactly, and the reason this was run before the other 454.

  The cause is structural, not a tuning error: MathPix finds regions the
  author never included as a file (TikZ figures, tables, displayed maths
  rendered as images), so the two sequences differ in length - 100 vs 134
  and 3 vs 9 - and every ordinal pair after the first extra region is
  offset. Ordering cannot be repaired by an offset either, because the
  extra regions are interleaved rather than appended.

CORROBORATION OF THE TRUTH ITSELF

  The region 5-tuple carries height and width, so a pair can be checked
  against the author file's shape independently of any caption.

  pair                               crop     file  verdict
  figures/ch2/reconstruct            1.34     1.29  MATCH
  figures/ch4/mpsch4                 3.51     2.96  differs - tikz-composed (expected)
  figures/ch4/getting_psi2           2.81     1.18  differs - tikz-composed (expected)
  figures/ch4/getting_psi3           1.66     1.18  differs - tikz-composed (expected)
  figures/ch4/getting_psi4           1.72     1.18  differs - tikz-composed (expected)
  figures/ch4/bhatt1.png             1.51     1.47  MATCH
  figures/ch4/bhatt2.png             1.57     1.54  MATCH
  img/nmf-f1.pdf                     1.74     1.81  MATCH

  Every unexplained-shape case would be a suspect pair. There are none:
  the four that differ are all tikz at-node placements, where the region
  crops the whole TikZ composition and not the included file - the same
  property 298 counted (239 of 239 tikz inclusions are node-placed). The
  four plain figures match within 12%. So the truth is corroborated where
  shape can speak, and explained where it cannot.

VERDICT

  The ordinal join is wrong on 8 of 8 known pairs. It must not run on the
  other 454 documents. 299 needs a join that uses the page and rectangle,
  not the sequence - and one that declines rather than returns a candidate
  it cannot distinguish.
