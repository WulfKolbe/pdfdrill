REASON 1 — THE SECTIONS ARE SEPARATE RUNS
------------------------------------------
  0902.0431: "run holds 30 data rows, the manifest expects 34"

10 corrected pairs is 30 lines, and the manifest totals 34 across sections.
`findings_tex` emits `\clearpage` BEFORE EACH SECTION, so the lattice sees
one run per section and my 561 concatenation asks it for one run of 34.
It works on 0707.4470 because that document has exactly one section.

So `equations_table` returning a concatenated pseudo-table is wrong for any
multi-section document. The measurement has to be per section, and the
results concatenated afterwards — not the manifest.

REASON 2 — A FAILED SWEEP DEGRADES THE PUBLISHED ARTEFACT
-----------------------------------------------------------
This is the one I should have foreseen and did not.

`inkreport` step 2 rebuilds `report.pdf` as a PHASE-1 build: legend off, no
ink. If step 3 then refuses, the run returns and **the published report.pdf
is left as the measure build**. Six of the nine were in that state when I
stopped:

  0902.0431  1605.05775  2010.14265  2106.07890  2501.06662
  BradleyGastaldiTerilla2023

Five of those are 1-page measure builds — documents whose findings sections
are empty, so there was never anything to measure. They were not failing a
measurement; they had none to do, and the run left them worse than it found
them.

All six restored to a reading build with legend, verified by their stamps.
No document is left in phase 1.
