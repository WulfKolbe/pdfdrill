ONE MORE THING THE AUDIT TURNED UP
----------------------------------
The Tables section reached the six-column shape 423 asked for — all 14
documents with tables have p{20}p{7}p{13}p{..}p{..}p{..} and a "Scan image"
header. The column is empty in every row: 0 of 351 table rows carry an
\includegraphics, against 8,718 of 8,718 equation rows that do.

The cause is data, not layout. download_crops filters on "_EQ" or "_TAB" in the
title — the intent is there — and then skips anything whose canonical_uri does
not start with http. Across the 21 models, 8,718 of 8,718 EQ tiddlers carry a
canonical_uri and 0 of 351 TAB tiddlers do. TAB tiddlers do carry page,
top_left_x, top_left_y, width and height, so the region is known and a local
render could fill the column; the CDN path cannot.

This is stated here because it changes what a republish is worth, not because
it was asked for.
