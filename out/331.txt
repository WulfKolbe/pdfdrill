WHAT THIS MEANS FOR 332, AND IT IS NOT WHAT 332 ASSUMES

  332 asks for 'a tikzcd environment from the source if the tree is the
  author's, or the MathPix region and its emitted LaTeX if it isn't'. The
  tree is not the author's, so the second branch applies -- but the second
  branch does not yield a gold set.

  These twenty crops have NO LaTeX. MathPix emitted an \includegraphics
  for each, which is the statement that it could not read them. There is
  no 'emitted LaTeX' to compare a proposal against.

  The author's 105 tikzcd environments ARE known-correct commutative
  diagram source, and they are in the same document -- but pairing one to
  a crop is the join 301 measured: 0 matched of 8 known pairs, because
  MathPix finds regions the author never wrote as a file and the two
  sequences interleave.

  So a gold set of twenty CDs with known-correct TikZ and a crop of each
  cannot be assembled from this directory by pairing. It can be built
  another way -- compile the author's tikzcd and render each one, which
  gives a picture whose correct source is known by construction and needs
  no join at all. The image is then a clean render rather than a page
  crop, which is a real difference and the reason to say so rather than
  quietly substitute it.
