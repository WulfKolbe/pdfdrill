CORRECTION TO 069 - THE ARROWS WERE NEVER DROPPED
------------------------------------------------------------------------------
   069 recorded that 0911.3722_EQ0019 "drops ALL THREE =>". That is WRONG,
   and the error was mine, not MathPix's. The stored LaTeX is

     _{<\omega} \text {-complete => } \text { Pack }_{n} \text {-complete }
     \text { => } \text { Pack }_{2} \text {-complete } \text { => }
     \text { pack }_{2}

   All three arrows are present. They are raw U+21D2 characters inside
   \text{}, and xelatex cannot set them:

     Missing character: There is no => (U+21D2) in font [lmroman10-regular]

   The glyph is dropped at RENDER time, in our own standalone pipeline. I
   read the rendered image and attributed to the OCR a loss that the
   renderer caused. 067's discipline - read the picture - is what made the
   original finding, and it is also what made this mistake: a picture shows
   what was drawn, not what was read.

   It is a WARNING, not an error, so the compile fixpoint's "^! " regex
   never sees it and the row is never demoted. The equation renders,
   silently missing three symbols, and its ink distance is inflated by
   exactly that.

   What IS a defect in EQ0019 stands: the leading "Pack" of the first term
   is absent from the LaTeX, and so is the trailing "-complete." Same
   truncation class as EQ0021. So the corrected verdict is unchanged in
   kind - both rows are content errors - but the mechanism is truncation at
   a boundary, not lost operators.

HOW WIDE IS THE MISSING-GLYPH DEFECT
------------------------------------------------------------------------------
   Measured rather than assumed. Every non-ASCII character in all 4,342
   corpus equation LaTeX values was collected and compiled through the
   standalone preamble:

     é       U+00E9   56 equations   renders
     ⇒       U+21D2    1             MISSING
     ⿱ ⿻ 一 日 」  CJK/ideographic-description   MISSING
     र ्     Devanagari                          MISSING

   5 equations corpus-wide carry a character the font cannot set. Four have
   confidence 0.02 to 0.58 and are CJK or Devanagari hallucinated onto a
   mathematics page - garbage either way. EQ0019, at 0.916, is the only
   sound reading affected.

   So the defect is real, silent, and rare: one row in 4,342 is materially
   misjudged by it. Worth fixing in the renderer (a fallback font, or
   mapping U+21D2 to \Rightarrow before compiling) and not worth revising
   any corpus number over.
