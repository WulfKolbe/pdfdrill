THE AMPERSAND, WHICH IS THE REAL OBSTACLE
------------------------------------------------------------------------------
A tikzcd uses `&` as its cell separator. So does the longtable it now sits in.
pgf reports "Single ampersand used with wrong catcode", 239 characters land in
`nullfont`, and the row is demoted:

    before   239 errors, 239 dropped glyphs, 53 rows demoted
    after      0 errors,   4 dropped glyphs, 54 rows demoted

tikz-cd carries the remedy — `[ampersand replacement=\&]` with the body escaped
to match — verified compiling standalone in a longtable cell at 0 errors and 0
missing characters. Existing options are merged, not clobbered. A
`tikzpicture` has no such option, so one containing a bare `&` (a `\matrix`
node) is refused rather than guessed at.

AND THE FIXPOINT COULD NOT DEMOTE A PICTURE
------------------------------------------------------------------------------
`compile_fixpoint` demoted a row by substituting `$\displaystyle …$`. A picture
cell is `\resizebox{…}{!}{…}` and never matched, so a failing row produced no
change, the loop broke, and the errors stayed in the document. `_demote_line`
now brace-matches the `\resizebox` argument — a regex cannot, the body of a
tikzpicture is full of braces — and leaves the row's other cells intact.

OFF BY DEFAULT — `--render-regions`
------------------------------------------------------------------------------
Because of one unresolved thing: with rendering on, this document drops 4
characters (U+0013, in DejaVu Serif) that it does not drop with rendering off.
Proved by A/B on the same document — rendering off, 0 missing; on, 4. The
character is in neither report.tex (0 control bytes) nor any tiddler, so
xelatex is generating it, and I have not found where.

Four characters in one document is small, and `publishready` refuses any report
that drops a glyph — correctly. Shipping this on by default would have made
that gate fail for documents it currently passes. So the flag is opt-in, no
existing report changes, and the hazard is written down rather than discovered
later by a failed publish.
