THE QUESTION
------------
"Why is this simple formula not rendered?" — mielke-geometrodynamics_EQ0857,
page 278, confidence 0.925, which a reader sees as "(not rendered)".

THE ANSWER, AND IT IS ONE CHARACTER
------------------------------------
The LaTeX is structurally sound: brackets balanced, environments balanced, no
alignment markers. `report_tex.display_safe` refuses it on exactly one gate,
`cjk_defect`, whose own message is the diagnosis:

    isolated CJK ideograph U+5315 (匕) — run length 1 (need >= 2 inside
    \text{}/\mbox{}/etc, >= 3 bare in math), so this is a DECOMPOSITION and
    not text

MathPix met a symbol it could not name and emitted a CJK stroke radical in
its place. Confirmed across the corpus: the other offenders are 一 十 二 丶
亻 宀 口 工 — stroke primitives — and gilmore-lie-groups_EQ0584 contains
⿰ ⿱ ⿺ ⿻, IDEOGRAPHIC DESCRIPTION CHARACTERS whose only purpose is to
describe how a character is composed. The recogniser was describing glyph
structure, not reading text.

THE PDF ALREADY KNOWS, AND IT IS FREE
--------------------------------------
For a born-digital document the page carries a SECOND, INDEPENDENT reading of
the same ink: its own text layer, plus the font `/Encoding` that names every
glyph the text layer cannot map to Unicode.

    Times-Roman /Encoding → /Lslash at code 173
    MTSYN       /Encoding /Differences [ 2 /angbracketleft /angbracketright
        /negationslash /asteriskmath /arrowright /logicaland /floorright
        /similarequal /similar /infinity /radical /minusplus … ]

Counting from code 2, code 8 is `/floorright`. So:

    row      MathPix wrote            the PDF says
    EQ0857   \mathbf{匕}               Ł            (Times-Roman /Lslash)
    EQ0472   \stackrel{十}{\Omega}     a literal +
    FO0431   \jmath  AND  」           /floorright BOTH TIMES — one symbol,
                                      two different wrong guesses

There is no `\pounds` in this book. The glyph is an L WITH A STROKE, exactly
as the user described it, and the font says so by name. And FO0431's own
surrounding prose, from the same text layer, reads "covariant Lie derivative
... on M with respect to an arbitrary vector field": the document names its
own symbol.

`(cid:N)` IS THE SIGNAL, NOT THE FAILURE
-----------------------------------------
A glyph with a `/ToUnicode` entry arrives as a character. One without arrives
as the literal `(cid:N)` — which marks EXACTLY the glyphs where the producer
supplied no Unicode and an OCR therefore had to invent. Measured over the 20
published documents: 604 distinct glyph names, 267 of them outside the Adobe
Glyph List — 267 names that arrive as `(cid:N)` and are otherwise lost. They
are the Computer Modern / MathTime / AMS conventions and are self-describing:

    parenleftbigg  \bigg(        lscript     ℓ (\ell)
    floorright     ⌋ (\rfloor)   similarequal ≅ (\cong)
    negationslash  the \not overlay          bardbl  \|
    integraldisplay \int         epsilon1    \varepsilon
    angbracketleft \langle       tildewide   \widetilde

WHAT WAS BUILT
--------------
`src/pdfdrill/glyphcensus.py` — evidence only, never a transcription:

    font_differences(pdf)   {BaseFont: {code: glyph name}}, one xref walk
    census(page, region, differences)  -> [Glyph] in reading order
    as_line / unmapped_names           what a prompt or report shows
    suspect_fonts(names)               fonts whose CHARACTERS cannot be trusted
    contradicts(latex, glyphs, *, own_region)   see below

pdfminer only — no mutool, no font parsing, no network. A scanned page yields
an empty census and says so; that is where ink is the only evidence.

THE CHECK THE INK GATE NEEDED
------------------------------
`contradicts()` exists because of a LIVE DEFECT this work uncovered:
mielke-geometrodynamics_EQ0378 publishes a SENTENCE OF ENGLISH PROSE in place
of its equation, on the site right now. A MiniMax refinement from 2026-08-26
was accepted because the ink distance FELL 106 → 10, and recorded with
`state: verified, verified_by: ink`. Ink distance measures how MUCH ink a
rendering makes, not whether it is the same ink — a short wrong line beats a
long damaged one, and the larger the claimed improvement the more suspicious
it should be (the other two accepted that day had deltas of −2 and are fine).

The census answers it: the letters and digits the PDF places in that region
are not in that sentence. Measured, the check flags it at 9 of 13 and 6 of 8
literal glyphs missing on EQ0472 and EQ0857 respectively, while passing every
faithful MathPix reading.

AND IT CAUGHT MY OWN DESIGN ERROR, ON ITS FIRST RUN
----------------------------------------------------
An inline Formula has no region, so a caller reaches for its HOST LINE's —
which is a whole line of prose. FO0431's host-line census holds 92 glyphs, 84
literal, so MathPix's correct 8-character reading appeared to be "missing" 49
of them. A confident false refusal. `own_region` is therefore REQUIRED and has
no default: declining is a decision a caller makes on purpose, and the wrong
scope cannot be passed by accident. `test_a_host_line_region_is_refused_
rather_than_misjudged` pins both directions.

WHAT THIS REPLACES
------------------
A three-layer design was proposed — text layer, then Type 1 charstring
outlines as PostScript for the LLM, then ink. Layer 2 IS NOT NEEDED for this
document class: `/Encoding /Differences` gives the glyph NAME, and a name is a
lookup, not an inference. A lookup cannot hallucinate, which is strictly
better than asking a model. The outline route stays reserved for pages with
no text layer, and for the 15-of-230 `Adv*` fonts that declare `WinAnsi` with
no `/ToUnicode` over symbol glyphs — the one shape where a text-layer census
yields plausible-but-wrong characters. `suspect_fonts()` names them.

1. EQ0378 WITHDRAWN — and the withdrawal keeps the sample
---------------------------------------------------------
`refine.withdraw_one(doc, obj_id, *, reason)` is `record_one`'s inverse: it
removes BOTH halves (the `latex_refined` twin prop and every
`provenance="change"` realization carrying it) so the object falls back to
its original `latex`, which was never overwritten.

    mielke-geometrodynamics_EQ0378   state verified -> none
    falls back to: D D \vartheta^{\alpha}=R_{\beta}{}^{\alpha} \wedge ...

IT RETURNS THE REMOVED VALUE RATHER THAN DELETING IT QUIETLY, and `reason` is
REQUIRED. A wrong acceptance is the most valuable sample this pipeline
produces — a labelled example of a gate being fooled, which cannot be
generated deliberately — so the value, its `verified_by`, its ink deltas and
the reason are written to `<doc>/withdrawn.json`. A refinement removed without
a reason is indistinguishable from one never recorded, which is the state the
function exists to be able to tell apart.

This is the first entry in what next week's GOLDEN SAMPLES work wants.

2. THE CENSUS IS NOW A VALIDATOR, and it caught its own false positive first
----------------------------------------------------------------------------
`validate_one(..., glyphs=, glyphs_own_region=)` runs `contradicts()` after
the CJK check and BEFORE the xelatex subprocess. Reason code `R_CENSUS`.

Every other check in that function is about the proposal's FORM — balanced,
compiles, uniform widths. None asks whether it is a reading of THIS REGION OF
THIS PAGE, and a well-formed English sentence passes all of them. One did,
for seventeen days.

Measured on EQ0378's real 72-glyph census:

    the prose that was published   REFUSED, "9 of 16 literal glyph(s) ...
                                   absent from the reading (026R)"
    MathPix's own reading          PASSES

THE FIRST VERSION REFUSED BOTH. Over the same real census it called 26 of 33
glyphs missing from the prose (right) and also rejected MathPix's correct
reading (wrong), because α β ϑ Π Σ ∼ ± were counted as literals the reading
lacked — LaTeX spells Greek as COMMANDS, not characters. A check that refuses
the right answer is worse than no check. The rule is now ASCII alphanumerics
only: the population LaTeX does spell literally. Pinned by
`test_greek_and_symbols_are_never_required_to_appear_literally`, which would
have failed before the fix.

Passing no census skips the check — the honest behaviour for a scanned page,
which has no text layer to census.

3. THE CENSUS IS IN THE PROMPT, with two rules aimed at what MiniMax did
------------------------------------------------------------------------
The propose prompt now explains what a census is (evidence, not a
transcription: no structure, may clip neighbours), gives the decisive glyph
names, and adds two rules, each written against a MEASURED failure from this
session:

  - "Change ONLY what is damaged" — MiniMax's EQ0472 proposal fixed 十 -> +
    correctly and silently DELETED `^{\{ \}}`. The census shows three `{ }`
    pairs on that page, so those braces are real notation.
  - "Return ONE reading of ONE expression" — its EQ0857 proposal fixed
    匕 -> \pounds correctly and appended `= \mathrm{Tr}\,\Omega \quad (=0)`
    from a neighbouring equation. Both failures are content BLEED, which the
    older batch shows repeatedly.
