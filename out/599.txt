     incomplete as an explanation because it does not hold on all of them.

  596 replaced ordinal selection with the identifier join, which was right

  row count, and the two count different populations. The old code hid the
  same disagreement behind _pages_for's "does not end on a page boundary"
  refusal; the new code surfaces it per page, which is better and still not
  a measurement.

WHAT WOULD FIX IT

  inkmeasure has to select rows WITHIN a page by identifier, rather than
  counting the page's rows and hoping the count matches. The identifier's
  position in the text layer is known; the lattice's row boxes are known;
  the join is between those two, not between two totals. That is a change to
  inkmeasure of the same size as 596 and it is not started.
