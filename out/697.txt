4. THE TASK, STEP BY STEP
  1. T0 export (no rendering): CSV/JSON per flagged row —
       mathpix_pdf_id, page, region (MathPix px), MathPix confidence, MathPix's own
       reading, our flag classes. No crops, no page images, no titles.
  2. Calibrate on the target machine: 20 documents spanning 13–500 pages at 4 / 8 / 12
     lanes; record s/row, peak RSS per lane, CPU per `inkdrill compare`. Pick the lane
     count; re-estimate before committing hours.
  3. Driver (`tools/`→ promote to a command if it stays): a queue ordered to mix large
     and small documents; per-document log + JSON; one writer per document (doclock);
     RESUMABLE — skip a document whose report.ink.json `measured_against` equals the
     model on disk; stop a document on its first failed step, never the run.
  4. Aggregate: per row the union of T0/T1/T2 classes; per-document and corpus counts;
     the same census re-run at the end must reproduce section 1's T0 numbers.
  5. Review: out/NNN.txt with the counts; the user reads it and decides what goes out.

  Target machine setup: the same repo (pip -e .), TeX Live with xelatex, Ghostscript,
