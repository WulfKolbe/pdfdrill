     still unbound at the point it was read. Initialised before the branch.

  2  AND THE ONE THAT WOULD HAVE SHIPPED. My first restructuring left
     `\end{document}` inside `if not findings:`, so every one of the 21
     builds aborted with

     and still reported a page count — TeX writes what it managed before
     giving up. The first table I produced said 5, 24, 18, 1, 1, … and looked
     entirely reasonable. A page count from an aborted compile looks exactly
     like a page count.

     Caught only because every one of 21 documents reported exactly one
     error, and a uniform error across a whole corpus is systematic rather
     than incidental. The corrected numbers are one page larger almost
     everywhere.

     There is now a test that `\end{document}` appears exactly once and that
     the file ends with it.
