WHY THIS IS A CONTROL AND NOT A MEASUREMENT
------------------------------------------------------------------------------
   040/057 compare two LaTeX strings held in the MODEL: MathPix's `latex`
   prop against the author's tex-provenance realization. 058 regenerated
   report.tex and report.pdf FROM the model, with mathrsfs and stmaryrd
   added to the preamble.

   Nothing on that path writes back to the model, so the prediction before
   running was 497/1,328 unchanged. A delta would not have been a better
   OCR score — it would have been evidence that report generation mutates
   its own input, which is a defect anywhere it happens. The run is
   therefore a negative control on 058, and it passes.

   This also bounds what 058 bought. 42 demoted rows now render, which is
   a change to what a READER sees. It is not a change to what MathPix
   produced, and no SLT number should be expected to reflect it. Anyone
   quoting 058's recovery as an accuracy improvement would be wrong.
