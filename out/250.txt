ONE DIRECTION, AS REVISED
------------------------------------------------------------------------------
The reverse check is not built. out/249 established that "equation", "figure"
and "caption" occur zero times in 4.0M MathPix line objects and are all live —
"equation" from the visionocr route, "figure"/"caption" asserted by
tests/test_picture.py. A check flagging them would have been answered by
allowlisting them, which is decoration.

The direction with teeth: a type MathPix emits that no module names produces
nothing, breaks nothing, logs nothing. That is exactly how `list_item` went
unread across 882 documents.

Two of the tests exist to stop the contract rotting into a comment:

   every CLAIMED type must actually appear in the module that claims it — an
   entry naming a module that does not mention the type is a claim about code
   that isn't there

   every IGNORED reason must lead with its kind (GAP / container only /
   sub-element / non-content) and be longer than a shrug. A type moved into
   IGNORED to silence the check, with a reason that does not survive being read
   aloud, defeats the check — and that is the only way this contract can fail
   quietly.
